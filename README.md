AI-Enhanced Intrusion Detection System
## About The Project

An AI-powered Intrusion Detection System designed to monitor network traffic, detect suspicious activities, and assess potential security threats using Machine Learning.

The project combines Snort, Python, and Random Forest with a Flask-based web interface to provide an intelligent cybersecurity monitoring solution.
## Technologies Used

- *Python:* Main programming language.
- *Snort:* Network intrusion detection and monitoring.
- *Raspberry Pi 5:* Hardware platform for system deployment.
- *Random Forest:* Machine learning algorithm for threat classification.
- *Flask:* Web framework for the monitoring interface.

- ## Key Features

- Real-time network traffic monitoring.
- Intrusion detection using Snort.
- Machine learning-based threat classification.
- Security risk assessment.
- Web-based monitoring dashboard using Flask.
- Integration with Raspberry Pi 5.
- ## System Architecture

The system consists of the following main components:

1. *Network Monitoring:* Captures and monitors network traffic using Snort.
2. *Data Processing:* Processes network data and prepares it for analysis.
3. *Machine Learning:* Uses the Random Forest algorithm to classify network activities.
4. *Risk Assessment:* Evaluates detected threats and their potential security impact.
5. *Web Interface:* Displays monitoring information and detection results through a Flask-based dashboard.
6. *Hardware Platform:* Uses Raspberry Pi 5 as the system's hardware platform.
